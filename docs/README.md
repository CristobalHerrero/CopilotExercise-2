# OctoAcme Project Management Docs

This repository contains the core project management process documents used by OctoAcme for planning, execution, communication, and continuous improvement.

## Project management process summary

OctoAcme follows a structured lifecycle for program work:
- Initiation to confirm the problem, stakeholders, and business value
- Planning to define scope, milestones, and delivery approach
- Execution to deliver work in small, testable increments with active tracking
- Risk management and communication to identify, mitigate, and escalate issues
- Release and deployment to move work safely into production
- Retrospective and continuous improvement to capture lessons learned and improve the process
